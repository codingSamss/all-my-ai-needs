# 安装与公开数据审查

rc.19 仅将等待画面替换为邮箱和 CC 小动作；主会话优先、后台记录、重载恢复、压缩动画及底栏规则不变。审查覆盖本次 Mod 绘图源码、许可证说明、版本与来源清单；安装器及无关 skills 未改动。

## 执行面与依赖

- `hooks/hooks.json` 仅加载自写 `register.tsx`，继续使用宿主时钟、session 用量/生命周期、state 和 UI resolve。
- 上下文只读取 `session.usage({breakdown: 'summary'})` 的本地估算，用同一摘要的 `totalTokens` 与 `autoCompactThreshold` 计算进度；不请求会触发远端计数的 `full` 明细，不读取个人配置文件，也不执行压缩。摘要中的文件/工具等明细不保留到插件 state。
- 在上下文变化或相关命令/配置变更后刷新摘要；命令和配置钩子先调用宿主 `next`，保留原结果。缓存秒表和额度刷新不会逐秒查询摘要；并发请求以最新请求为准，读取失败清除旧阈值。
- `session.compact` 仅观察主会话非预计算事件；完整透传消息和结果，不保存待压缩的内容。独立计数清理并发状态，跳过和失败也退出动画；界面异常不阻断压缩，结束后仅刷新一次本地 summary。
- 等待状态观察前台工具、代理和宿主任务通知/完整快照，不读取命令内容来猜进度；会话 ID、任务 ID 与顺序号仅存于插件状态，不查询系统进程或日志。只有宿主 task-notification 来源会按协议解析完成状态，普通用户内容不能改变任务状态。
- 缺失/非法快照只降低完整性，不清除已确认的后台任务；启动与客户端重新连接仅各读取一次 `agent.list()`，只存 ID/状态，不保存描述。代理列表不等于全局 shell 列表；列表缺失、失败或为空不会清掉 shell。相同会话 ID 才接续热重载前的后台记录，首次加载的未知任务仍等宿主快照。
- 主会话真实压缩、主会话工作均优先于等待场景；工作判断直接使用宿主 `isWorking`，不根据对话内容推测；并发压缩计数和等待任务分别管理，会话代次阻止旧压缩回调修改新会话或刷新读数。
- `scene.ts` 只保留纯 SVG 绘图；不引入上游工具分类、结果正则、300 ms 轮询、节日或历史日志读取。MIT 原文及固定提交保留在 `scene-NOTICES.txt`。
- 字体与图标为包内授权子集，未知字符回退宿主 Text；不加载外部资源。
- 安装器仅依赖 Python 标准库与官方 Claude CLI；包内代码/许可证受 SHA-256 清单保护，组装不再下载远端文件。

## 安装器读写

读取本目录源码/来源清单、指定插件的登记字段及安装进程信息。不读取认证文件、Keychain、会话历史或项目内容，不输出完整配置/环境变量/进程命令行。
生成物只进入设备私有缓存；符号链接、源码漂移、未知内容、并发或版本差异触发停止。同版本且文件一致时重复安装不改设置。
市场、安装、启用和已审阅升级交给官方 CLI；不手写安装登记，不改权限/MCP，不重启 App、不重载现有会话。

## 已验证与局限

rc.19 在 CLI 内核 2.1.299 通过 57 项宿主 SDK 测试、13 项安装器测试及官方插件静态验证，errors / warnings 均为空。测试覆盖主会话工作优先、脚本与 subagent 并行等待、最后一项结束后退出、缺失快照、乱序通知、重载恢复、跨会话隔离、真实压缩与阈值、额度及固定高度布局；状态判断源码未修改。

实际输出的等待 SVG 已在浏览器检查浅深配色、54px 高度、场景宽度 280px 时的居中裁边、四类动作及完整 8 秒 SMIL 循环；逐帧确认同一时刻仅一组角色姿态可见，循环结束回到等候姿态。减弱动态效果的静止分支已检查。邮箱始终为空，信封图案与旗帜不变；动画不编码完成比例或预计耗时。其余六景的输出与 rc.18 逐字节一致；保留透明底色、完整额度组件及原生目录入口。

本机通过官方 CLI 从 rc.18 升级到 rc.19，17 个安装文件与来源清单哈希一致。旧 rc.18 源文件及私有缓存保留，用户设置与其他插件登记未变；未重启 App、未重载会话。CLI 可为旧缓存添加 `.orphaned_at` 管理标记。

浏览器检查使用示例额度，不等于原生 Desktop 场景验收。检查时原生会话仍有后台任务运行，因此没有重载或发送测试提示词；rc.19 的真实任务切换与长期运行仍待新会话或任务结束后的重载验收，保持 candidate。模拟一小时同一状态仅一份动画源，不是实际 App 的 CPU、内存或长期稳定性结论。上下文数值仍来自宿主估算，达到阈值仅表示已达压缩线，不表示压缩已执行或剩余 token 有精确保证。

提交前通用凭据扫描、私有敏感模式扫描与本次改动的个人绝对路径检查均无命中；设备私有规则仅在本地使用，不进入仓库。
