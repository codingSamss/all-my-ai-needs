# 安装与公开数据审查

rc.4 在 MIT 授权的 pixel-at-work 绘图子集上增加浅色白天/深色夜晚场景；审查覆盖本次 Mod 源码、安装器、来源清单和说明，不涵盖无关 skills。

## 执行面与依赖

- `hooks/hooks.json` 仅加载自写 `register.tsx`，继续使用宿主时钟、session 用量/生命周期、state 和 UI resolve。
- `scene.ts` 只保留纯 SVG 绘图；不引入上游工具分类、结果正则、300 ms 轮询、节日或历史日志读取。MIT 原文及固定提交保留在 `scene-NOTICES.txt`。
- 字体与图标为包内授权子集，未知字符回退宿主 Text；不加载外部资源。
- 安装器仅依赖 Python 标准库与官方 Claude CLI；包内代码/许可证受 SHA-256 清单保护，组装不再下载远端文件。

## 安装器读写

读取本目录源码/来源清单、指定插件的登记字段及安装进程信息。不读取认证文件、Keychain、会话历史或项目内容，不输出完整配置/环境变量/进程命令行。
生成物只进入设备私有缓存；符号链接、源码漂移、未知内容、并发或版本差异触发停止。同版本且文件一致时重复安装不改设置。
市场、安装、启用和已审阅升级交给官方 CLI；不手写安装登记，不改权限/MCP，不重启 App、不重载现有会话。

## 已验证与局限

安装器未改变；rc.4 宿主 SDK 14 项测试通过，继承 rc.3 安装器 13 项测试；验证使用 CLI 内核 2.1.294。
覆盖离线完整包、许可缺失、并发/漂移/越界、额度与 ctx、主会话阶段和错误/中断/子任务、固定高度裁边容器。
模拟一小时同一状态仅 1 份动画源，额度查询一次；这不是实际 App 的 CPU、内存或长期稳定性结论。
隔离环境的首次/重复安装和本机官方 CLI 升级通过，安装包文件一致；旧版源码哈希保持不变，CLI 为旧缓存添加了 `.orphaned_at` 管理标记。
rc.3 浏览器源码预览已检查 460/600/768px 的单行裁边效果；rc.4 已检查浅深两套画面和不更换 SVG 的主题切换。现有 Desktop 运行会话仍显示旧版；空白会话未启动引擎时不显示 Mod，因此未通过发送提示词来强行验收。
新增部分只有 SVG 图形、媒体查询和颜色变量，无新增插件定时器、数据读取或网络请求。真实 Desktop 的主题、窗口尺寸、完整动画阶段与持续性能需在下次新会话启动后验收，保持 candidate。
本次 Mod 范围的通用凭据及个人绝对路径扫描无命中；本机缺少 `.secrets-patterns.local`，私有模式未扫描。
