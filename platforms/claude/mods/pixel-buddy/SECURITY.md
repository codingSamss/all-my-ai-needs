## 执行面与依赖

- 运行入口为 `source/hooks/hooks.json` 指向的 `register.tsx`。自写入口仅使用宿主时钟、session 用量/事件、state 和 UI resolve。
- 静态辅助文件为像素图标、数字与中文子集；未知字符/超宽标签回退宿主 Text，不执行 HTML 或加载外部字体。
- 宠物 `scene.ts` 不在公开仓库；从 `origin.json` 指定的固定提交匿名下载，按 SHA-256 和大小上限验证后才组装。
- 安装器仅依赖 Python 标准库和已有的官方 Claude CLI；无 pip/npm 安装、第三方 setup 脚本、模型请求或 shell=True。

## 安装器读写与网络

只读取本目录的源文件/来源清单、指定插件的本机登记字段及安装进程信息。
不读取 Keychain、Claude 认证文件、会话历史或项目内容；不保存/输出整个 settings、环境变量或进程命令行。
主动网络请求只有一个固定 GitHub raw 文件，不发送 Claude 凭据；拒绝重定向、过大文件和哈希不符内容。
CLI 自身的登录/管理策略仍由官方 CLI 处理；安装器不绕过管理员策略或自动登录。

生成文件只进入仓库之外的设备私有缓存。缓存目录有符号链接、包内容异常或文件漂移时停止，不覆盖、不清理。
不同缓存路径安装时仍共享配置锁；同版本重复执行不会重复登记或改设置。
user scope 的市场/安装/启用操作通过官方 CLI 完成；不手写登记文件，不改 permissions、MCP 或隐私设置。
不自动禁用原版、不发送提示词、不重启 App、不重载当前会话。
