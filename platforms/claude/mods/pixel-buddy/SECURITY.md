## 执行面与依赖

- `hooks/hooks.json` 仅加载自写 `register.tsx`，继续使用宿主时钟、session 用量/生命周期、state 和 UI resolve。
- 上下文只读取 `session.usage({breakdown: 'summary'})` 的本地估算，用同一摘要的 `totalTokens` 与 `autoCompactThreshold` 计算进度；不请求会触发远端计数的 `full` 明细，不读取个人配置文件，也不执行压缩。摘要中的文件/工具等明细不保留到插件 state。
- 在上下文变化或相关命令/配置变更后刷新摘要；命令和配置钩子先调用宿主 `next`，保留原结果。缓存秒表和额度刷新不会逐秒查询摘要；并发请求以最新请求为准，读取失败清除旧阈值。
- `session.compact` 仅观察主会话非预计算事件；完整透传消息和结果，不保存待压缩的内容。独立计数清理并发状态，跳过和失败也退出动画；界面异常不阻断压缩，结束后仅刷新一次本地 summary。
- 等待状态观察前台工具、代理和宿主任务通知/完整快照，不读取命令内容来猜进度；会话 ID、任务 ID 与顺序号仅存于插件状态，不查询系统进程或日志。只有宿主 task-notification 来源会按协议解析完成状态，普通用户内容不能改变任务状态；信封须在文本开头，或紧跟宿主固定的系统通知声明（可再包一层 system-reminder），其他前缀一律不认；摘要和结果正文里引用的信封不参与判断；终态限 completed、failed、killed、stopped。
- 快照里 `type` 标签属于监视、记忆整理、自动模式扫描、记忆导入的任务，或任务 ID 符合宿主为这些类型生成的规则（`s` / `m` / `d` / `e` / `n` 加 8 位字母数字），不计入等待；重载接续旧记录时同样过滤。快照里每条任务的类型标签仅作文字记入插件状态（最多 30 条、限长并替换异常字符），不保存描述、命令或路径。
- `/buddy-status` 是只读命令（登记为 immediate，回合进行中也能运行）：运行时读一次面板状态和一次 `agent.list()`，输出任务 ID、类型、是否被宿主快照确认、被忽略的监视类任务、代理的 ID / 状态 / 类型和计数，不含代理描述、名称、命令内容或路径，异常字符会被替换，每段最多 20 行；输出与其他命令一样写入对话记录，模型读得到。登记在唯一的 `session.start` 钩子内，失败只少这个入口；命令不写状态、不重载、不触发其他命令，也没有定时器。
- 缺失/非法快照（含条目缺 ID、缺状态或 ID 不合法）只降低完整性，不清除已确认的后台任务；状态词不认识的单条按未列出处理，不作废整份快照；主回合结束时仅清除当时已登记、仍没返回的前台调用，后台任务不受影响；启动与客户端重新连接仅各读取一次 `agent.list()`，只存 ID/状态，不保存描述。代理列表不等于全局 shell 列表；列表缺失、失败或为空不会清掉 shell。相同会话 ID 才接续热重载前的后台记录，首次加载的未知任务仍等宿主快照。
- `turn.step` 只观察响应块的种类（thinking / text / tool）来区分思考、回复与干活，不读取也不保存文本、思考内容或工具参数；每个块原样 `yield`，最终结果原样返回，装饰层读写失败不打断模型响应；子代理的请求直接透传。
- `AskUserQuestion` 与 `ExitPlanMode` 的 `tool.call` 只在调用前后各改一次提问计数，输入、结果和异常原样透传；计数与会话代次绑定，旧回调不能改新会话，更新失败不阻断真实提问。其他工具的权限确认与执行同在一次调用内，无法区分，不在观察范围。
- `turn.complete` 只读取结束原因（error / refusal / aborted）来决定出错或中断画面，不读取错误文本；约 6 秒的一次性计时器按阶段时间戳核对，已开始新一轮时旧计时器不会覆盖。
- 新增的面板状态只有枚举（思考 / 干活 / 回复、咖啡温度三档）和提问计数，没有文本、命令、路径或错误内容；咖啡温度借用已有的每秒节拍，只在跨档时写入面板。
- 主会话真实压缩、等你回答、主会话工作均优先于等待场景；工作判断直接使用宿主 `isWorking`，不根据对话内容推测；并发压缩计数和等待任务分别管理，会话代次阻止旧压缩回调修改新会话或刷新读数。
- `scene.ts` 只保留纯 SVG 绘图，软木板为固定图案，不显示任何真实任务内容；不引入上游工具分类、结果正则、300 ms 轮询、节日或历史日志读取。MIT 原文及固定提交保留在 `scene-NOTICES.txt`。
- 字体与图标为包内授权子集，未知字符回退宿主 Text；不加载外部资源。
- 安装器仅依赖 Python 标准库与官方 Claude CLI；包内代码/许可证受 SHA-256 清单保护，组装不再下载远端文件。

## 安装器读写

读取本目录源码/来源清单、指定插件的登记字段及安装进程信息。不读取认证文件、Keychain、会话历史或项目内容，不输出完整配置/环境变量/进程命令行。
生成物只进入设备私有缓存；符号链接、源码漂移、未知内容、并发或版本差异触发停止。同版本且文件一致时重复安装不改设置。
市场、安装、启用和已审阅升级交给官方 CLI；不手写安装登记，不改权限/MCP，不重启 App、不重载现有会话。
